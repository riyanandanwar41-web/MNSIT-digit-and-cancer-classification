# MNSIT-digit-and-cancer-classification
MNSIT digit classification using neural network and Cancer classification using neural network 
AI PROJECT
Project overview
The MNSIT Digit Classification project is a beginner-friendly Artifitical Intelligence and machine learning project that focus on recongnizing handwritten digits (0-9) using neural network model.
Cancer Classification Using Neural Networks is an AI-based healthcare project designed to classify tumors as Benign (Non-Cancerous) or Malignant (Cancerous) using medical datasets.

Project Objectives
•	 Understand the fundamentals of Neural Networks. 
•	Learn image classification techniques.
•	Train a model using the MNIST dataset.
•	Develop an intelligent cancer prediction system. 
•	Understand classification algorithms. 
•	Learn healthcare data analysis techniques.
